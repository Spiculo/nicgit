# First run: the welcome questionnaire

**Status:** Implemented · **Date:** 2026-11-26
**Scope:** NicGit web app and account API · **Related:** decisions N60, N61, N62;
[wording styles](2026-11-26-wording-styles.md)

A new person signs in with Google, then answers three short pages before the app opens. The answers
set the language and wording immediately; the practice details are stored so later defaults can use
them.

---

## 1. Flow

1. **Language and wording**
   - English or Español.
   - Git wording or architectural wording, with one-line examples.
   - The welcome page itself re-renders in the selected language and wording, so the choice is visible
     before it is saved.
2. **Work**
   - Field: architect, engineer, contractor/builder, project manager, client/owner, student, other.
   - Years in the field: 0–80.
   - Site experience: none, a little, regular visits, extensive.
   - Project focus: residential, commercial, public, infrastructure, interiors, education, other
     (optional).
3. **Team**
   - Company (optional, 120 characters).
   - People you work with: just me, 2–5, 6–20, 21–50, 51+ (optional).
   - People at your company: 1–10, 11–50, 51–200, 201–1000, 1000+ (optional).
   - **Enter NicGit** saves and opens Home.

A person can sign out from the welcome card. Back and Continue keep the answers in local state. A
failed save shows one error and leaves the answers in place.

## 2. Routing

- `GET /api/me` returns `onboarded`.
- When `onboarded` is false, every signed-in route redirects to `/welcome`.
- `/welcome` hides the top bar and renders the welcome card on the construction-grid background.
- After the save, the client waits for `/api/me` to refetch, then opens `/`.
- Existing accounts were marked as onboarded by the migration. They can update the answers from
  **Settings → Profile → Work profile**, which opens the same `/welcome` card.

## 3. Data

`POST /api/me/onboarding` accepts:

```json
{
  "lang": "en",
  "style": "git",
  "work": "architect",
  "years_experience": 12,
  "site_experience": "regular",
  "focus": "residential",
  "company": "Studio Ferreira",
  "team_size": "six_to_twenty",
  "company_size": "eleven_to_fifty"
}
```

Validation:

- `lang` is `en` or `es`; `style` is `git` or `architecture`.
- `work`, `site_experience` and `years_experience` are required and checked against the lists above.
- `focus`, `team_size` and `company_size` are empty or checked against their lists.
- `company` is trimmed and at most 120 characters.
- The update sets `onboarded_at = coalesce(onboarded_at, now())`, so editing from settings keeps the
  original date.
- The action is written to the audit log as `user.onboarding`.

Migration `0008_onboarding.sql` adds to `users`:

| Column | Type | Meaning |
|---|---|---|
| `onboarded_at` | timestamptz | Null until the flow is complete |
| `work` | text | Field code |
| `years_experience` | integer | 0–80 |
| `site_experience` | text | Site code |
| `focus` | text | Project focus code |
| `company` | text | Company name |
| `team_size` | text | Team size code |
| `company_size` | text | Company size code |

`GET /api/me` returns all of them, plus `onboarded`.

## 4. What the answers change today

- **Language** and **wording** apply immediately and remain editable in Settings → Language & wording.
- Work, site experience, focus, company and team size are stored and audited. They do not yet change
  project defaults, permissions or copy; they are the basis for later defaults.

## 5. Acceptance criteria

1. A new account lands on `/welcome` after sign-in.
2. The welcome card changes language and wording live as the choices change.
3. Continue is blocked on the work step until field, years and site experience are set.
4. The third step saves and opens Home.
5. The save sets `onboarded`, language, wording and the practice fields on the account.
6. `GET /api/me` returns the saved values; a later visit to `/welcome` prefills them.
7. Existing accounts are not blocked; they reach the flow from Settings → Profile.
8. A failed save leaves the person on the card with an error, not a blank page.
9. The card holds at 800 px and at 390 px.
